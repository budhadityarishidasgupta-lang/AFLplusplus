# SB-49.P5A — UAT Configuration Isolation

The standalone SearXNG UAT runner accepts `--config-dir` with an absolute path to a local configuration directory and requires `--config-dir-approved` as explicit owner confirmation. It rejects detected symlink redirection and reads only `SEARXNG_ENDPOINT`, `SEARXNG_API_TOKEN`, and `SEARXNG_APPROVED` from that directory's `.env`; it does not copy or modify the file. Default mode remains offline. Live requests still require both `--live` and `--credential-rotation-confirmed`, and the approval setting must remain disabled.

The tracked-source scanner permits `.env.example` as a template but scans its content for credential patterns. Other tracked `.env*` files continue to be reported as environment-file findings.

Offline tests use synthetic values only. No production credentials, live requests, deployment, or approval changes are part of this follow-up.
